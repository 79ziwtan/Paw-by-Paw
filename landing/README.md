# Waffle landing page

The public landing page for Waffle, kept separate from the app in the repo root.
It's one plain HTML file (`index.html`): no build step, no dependencies.

**Preview locally:** open `index.html` in a browser.

**Deploy (Netlify, free):** Add new site → Import from GitHub → pick this repo →
set **Base directory** to `landing` → Deploy. Pilot sign-ups appear under
Site → Forms (Netlify Forms; enable form detection the first time).
